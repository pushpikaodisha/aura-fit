# AuraFit

> Personal Fitness, TDEE & HIIT Workout Tracker

![HTML5 / CSS3](https://img.shields.io/badge/HTML5_%2F_CSS3-1e293b?style=flat-square) ![Bootstrap 5](https://img.shields.io/badge/Bootstrap_5-1e293b?style=flat-square) ![Vanilla ES6 JS](https://img.shields.io/badge/Vanilla_ES6_JS-1e293b?style=flat-square) ![LocalStorage API](https://img.shields.io/badge/LocalStorage_API-1e293b?style=flat-square) ![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

![AuraFit Official Banner](assets/banner.svg)

## 📌 Executive Overview
Responsive fitness dashboard featuring Mifflin-St Jeor TDEE calculations, hydration goals, exercise checklist tracking, and an interval HIIT workout timer backed by `localStorage`.

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pushpikaodisha/aura-fit.git
   cd aura-fit
   ```

2. **Launch locally:**
   Open `index.html` directly or serve via any static HTTP server (`npx serve .`).
